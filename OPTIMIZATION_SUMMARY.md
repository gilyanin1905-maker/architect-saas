# Оптимизация проекта Architect SaaS

## Обзор улучшений

### 1. Безопасность 🔒
- **Вынесен API ключ OpenRouter** из кода в переменные окружения (.env)
- Создан `.env.example` для шаблона конфигурации
- Добавлен `.env` в `.gitignore` для предотвращения утечки ключей

### 2. Производительность ⚡

#### ChatInterface.tsx
- API ключ теперь загружается из переменных окружения
- Добавлены типы для `import.meta.env` в `vite-env.d.ts`

#### App.tsx
- Уже использует `React.lazy` для ленивой загрузки компонентов
- Использует `React.memo` для предотвращения лишних рендеров
- Lazy loading для всех тяжёлых компонентов

#### SpaceBackground.tsx
- Оптимизировано количество частиц (уменьшено до 15)
- Добавлен `contain: strict` для оптимизации рендеринга

#### EvaRobot.tsx
- Использует `requestAnimationFrame` для плавных анимаций
- Canvas-рендеринг вместо DOM-элементов для лучшей производительности

### 3. Качество кода 🧹

#### Добавлен ESLint
- Конфигурация для TypeScript и React
- Правила для React Hooks
- Предупреждения об использовании `any`
- Проверка неиспользуемых переменных

#### Добавлен Prettier
- Единый стиль форматирования кода
- Консистентное форматирование во всех файлах
- Конфигурация для двойных кавычек, табуляции 2 пробела

#### Модульная структура констант
- Создана папка `constants/` для лучшей организации
- `constants/animation.ts` - константы анимаций
- `constants/uiText.ts` - тексты интерфейса
- `constants/index.ts` - централизованный экспорт

### 4. Исправления ошибок 🐛

#### Удалены неиспользуемые импорты
- `BotIcon` из Hero.tsx (не использовался)
- `UI_TEXT` из BlogModal.tsx (не использовался)
- `useCallback`, `useMemo` из EvaRobot.tsx (не использовались)
- `ChevronDown` из ChatInterface.tsx (не использовался)
- `useScroll`, `useTransform` из ROICalculator.tsx (не использовались)
- `currentYear` из Footer.tsx (не использовался)
- Неиспользуемые переменные в ContactForm.tsx

#### Исправлен импорт типов
- Navbar.tsx: исправлен путь к `types.ts` с `../types` на `./types`

## Команды для разработки

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Линтинг кода
npm run lint

# Автоисправление линтера
npm run lint:fix

# Форматирование кода
npm run format

# Проверка форматирования
npm run format:check

# Предпросмотр сборки
npm run preview
```

## Конфигурация переменных окружения

Создайте файл `.env` в корне проекта:

```env
# OpenRouter API Configuration
VITE_OPENROUTER_API_KEY=your_api_key_here
VITE_OPENROUTER_MODEL=google/gemini-2.0-flash-001

# Site Configuration
VITE_SITE_URL=https://architect-saas.dev
VITE_SITE_NAME=Architect SaaS
```
