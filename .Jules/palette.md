## 2026-07-28 - Explicit Input-Label Linking in Snap-Scroll Layouts
**Learning:** In highly structured single-page applications utilizing CSS snap-scrolling and lazy-loaded elements (such as Framer Motion triggers), failing to explicitly link inputs or sliders via standard 'id' and 'htmlFor' attributes degrades both modern screen readers and native browser behaviors (such as automated label-click focusing). Furthermore, automated Playwright/visual verifications of these layouts suffer from selector duplications unless elements are scoped and specifically scrolled into view before interaction.
**Action:** Always link labels explicitly to their targets with unique IDs (especially prefixing them to avoid global namespace collisions), ensure proper viewport scrolling before interacting, and use scoped selectors (.first or index-specific locators) in automated tests to prevent strict-mode DOM matching errors.
