## 2026-07-16 - [Form Success & Reset Focus Preservation]
**Learning:** When dynamic state transitions (such as switching from a form to a success layout) occur, screen reader users and keyboard navigators lose focus and context. Simply utilizing "status" alert regions is not enough; programmatic focus must be guided to the success block. Additionally, when a user decides to "send again" (resetting the form), focus must be elegantly returned back to the first input field to prevent random document-level focus jumps.
**Action:** Always couple `aria-live="polite"` and `role="status"` on success nodes with a programmatic `.focus()` call via React refs on component update. Use a `prevStatusRef` hook to differentiate mount-time updates from explicit user action resets to direct focus precisely to the first form input.
