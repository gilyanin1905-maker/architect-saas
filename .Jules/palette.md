## 2025-05-15 - [Form Accessibility & Focus Management]
**Learning:** For async forms, providing visual feedback is only half the battle. Accessibility requires connecting labels correctly and managing focus between states (e.g., from form to success message and back) to ensure a seamless experience for screen reader and keyboard users.
**Action:** Always use 'htmlFor'/'id' pairings, add 'autoComplete' for better UX, and use React refs to manage focus transitions between interactive states.
