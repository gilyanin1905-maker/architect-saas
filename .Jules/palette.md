## 2026-08-10 - Keyboard Accessibility and Focus Management in Drawer Dialogs
**Learning:** Implementing bottom-drawers, overlays, or modal dialogs requires managing the keyboard navigation lifecycle (Escape to dismiss, auto-focusing elements when mounted, and restoring focus back to the previously active element when dismissed) to prevent screen reader and keyboard user disorientation and focus trap/context loss.
**Action:** Always capture `document.activeElement` prior to drawer visibility changes, programmatically shift focus to the primary close action or first focusable element inside the drawer after mounting (using a small timeout if needed for dynamic/Framer Motion rendering), listen for global `Escape` key interactions, and restore focus to the saved element upon unmounting.
