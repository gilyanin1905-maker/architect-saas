## 2026-07-06 - Dynamic Focus Management in React/Framer Motion State Transitions

**Learning:** In highly animated or dynamic state-transition environments (such as Framer Motion's AnimatePresence), simply updating the DOM or showing success messages does not guarantee screen reader users will notice the transition. Assistive technologies can lose focus completely when the active form elements are unmounted or hidden. Programmatic focus shifting to a focusable status container (using tabIndex={-1} and role="status") is critical to preserve user context. Additionally, when resetting state, returning focus to the first interactive element must be done carefully using a previous-state check (e.g., tracking previous status via a ref) to prevent unintended autofocus and layout jumps on the initial page mount.
**Action:** Always identify elements that enter/exit the DOM during state changes. Set a tabIndex={-1} on the entry status wrapper, focus it programmatically on transition, and use ref-based state checks to safely restore focus on form resets without triggering initial mount side-effects.
