## 2025-05-14 - Visual Feedback for Copy Action
**Learning:** Users often experience uncertainty when interacting with icon-only buttons that perform background actions (like clipboard copying). Providing immediate visual feedback through state changes (icon swaps, color changes, and temporary labels) significantly improves the perceived responsiveness and reliability of the interface.
**Action:** Always implement a "success" state for copy buttons and similar asynchronous/background triggers to confirm action completion to the user.
